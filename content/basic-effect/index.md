This is the course. The first ten chapters build a service that fetches real
data over a real network, retries what is worth retrying, and has tests that
prove it. Chapter eleven steps back and shows how to design that kind of program
before writing it.

Read the chapters in order. Each one earns the next, and the code from chapter
three is still being used in chapter ten. The last chapter draws the design
behind that code.

The snippets marked with a type reveal are compiled when this site is built. An
example that does not typecheck fails the build instead of reaching you.
