This is the course. It starts with why a program might be worth representing as
a value, and ends with a service that fetches real data over a real network,
retries what is worth retrying, and has tests that prove it.

Read the chapters in order. Each one earns the next, and the code from chapter
three is still being used in chapter ten.

Every chapter ends with something you can paste into a file and run. Nothing
here is pseudocode: the snippets marked with a type reveal are compiled when
this site is built, so an example that does not typecheck fails the build
instead of reaching you.
