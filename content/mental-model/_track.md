Most people who bounce off Effect do not bounce off the API. They bounce off
writing TypeScript the way they always have, with an Effect-shaped wrapper
around it, and finding that it costs more and gives nothing back.

This track is about the shift itself. Each page takes one habit you already
have, shows what it stops you doing in Effect, and names the replacement. There
is no library tour here, and you need no prior Effect to read it.

The last page is different. It assumes you have finished Basic Effect, and it
covers designing a program before writing it.
